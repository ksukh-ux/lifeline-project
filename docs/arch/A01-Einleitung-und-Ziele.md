# 1. Einführung und Ziele

## 1.1 Aufgabenstellung
Die Life Timeline App visualisiert Lebensereignisse (Reisen, Jobs, Projekte)
als chronologische Zeitleiste, ermöglicht Filterung nach Kategorie und zeigt
aggregierte Statistiken (Zeit gearbeitet vs. gereist).

## 1.2 Qualitätsziele
1. Benutzbarkeit – die Timeline muss intuitiv bedienbar sein, auch ohne Anleitung
2. Wartbarkeit – klare Komponentenstruktur, damit vier Personen parallel arbeiten können
3. ...

## 1.3 Stakeholder

| Rolle | Erwartung |
|---|---|
| Nutzer:innen | einfache, verständliche Bedienung |
| Team | wartbarer, verständlicher Code für den Walkthrough |
| Betreuer | nachvollziehbare Architekturentscheidungen, Konsistenz zur Spec |
