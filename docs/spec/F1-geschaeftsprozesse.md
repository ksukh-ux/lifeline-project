# F1 – Geschäftsprozesse

## F1.1 Benutzerzugang verwalten

Der Nutzer kann sich bei Lifeline registrieren und anschließend anmelden, um auf die Anwendung zuzugreifen.

Der Geschäftsprozess umfasst die folgenden Schritte:

1. Der Nutzer öffnet die Lifeline-Anwendung.
2. Der Nutzer registriert sich mit seinen Zugangsdaten oder meldet sich mit einem bestehenden Konto an.
3. Die eingegebenen Zugangsdaten werden an das Backend übertragen.
4. Das Backend prüft die Zugangsdaten.
5. Bei erfolgreicher Anmeldung erhält der Nutzer Zugriff auf die Anwendung.
6. Der Nutzer wird zur Timeline weitergeleitet.

## F1.2 Timeline und Events verwalten

Der Nutzer kann persönliche Events in seiner Timeline anlegen, anzeigen, bearbeiten und löschen.

Der Geschäftsprozess umfasst die folgenden Schritte:

1. Der Nutzer öffnet seine Timeline.
2. Der Nutzer kann vorhandene Events chronologisch betrachten.
3. Der Nutzer kann ein neues Event anlegen.
4. Der Nutzer gibt die Informationen des Events ein.
5. Das System prüft die eingegebenen Daten.
6. Das Event wird gespeichert und in der Timeline dargestellt.
7. Der Nutzer kann ein vorhandenes Event bearbeiten.
8. Der Nutzer kann ein nicht mehr benötigtes Event löschen.

## F1.3 Timeline filtern

Der Nutzer kann die Darstellung der Timeline nach Kategorien filtern.

Der Geschäftsprozess umfasst die folgenden Schritte:

1. Der Nutzer betrachtet seine Timeline.
2. Der Nutzer wählt eine Kategorie als Filter aus.
3. Die Timeline wird auf Basis der bereits geladenen Events entsprechend der ausgewählten Kategorie gefiltert.
4. Der Nutzer kann den Filter wieder ändern oder entfernen.

## F1.4 Statistiken auswerten

Der Nutzer kann aggregierte Informationen zu seinen Events als Statistik betrachten.

Der Geschäftsprozess umfasst die folgenden Schritte:

1. Der Nutzer öffnet die Statistikansicht.
2. Das System fordert die vorhandenen Event-Daten an.
3. Die Daten werden nach Kategorien ausgewertet.
4. Das System berechnet die benötigten aggregierten Werte.
5. Die Statistik wird dem Nutzer in der Statistikansicht dargestellt.
