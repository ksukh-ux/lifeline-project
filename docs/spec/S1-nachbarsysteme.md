# S1 – Nachbarsysteme

Die Lifeline-Anwendung besitzt aktuell keine angebundenen externen Nachbarsysteme.

## S1.1 Nutzer:in

Die Nutzer:in ist der externe Akteur, der mit Lifeline interagiert.

### Schnittstelle

Die Kommunikation zwischen Nutzer:in und Lifeline erfolgt über den Webbrowser.

### Übertragungsprotokoll

HTTPS

### Eingaben

- Formulareingaben
- Anfragen über den Browser
- Aktionen zur Verwaltung von Events

### Ausgaben

- Gerenderte Timeline-Ansicht
- Antworten auf Anfragen
- Bestätigungen und Fehlermeldungen

## S1.2 Keine weiteren Nachbarsysteme

Aktuell ist kein weiteres externes System an Lifeline angebunden.

Die Kommunikation zwischen Frontend, Backend und Datenbank erfolgt innerhalb des Lifeline-Systems und wird daher nicht als Kommunikation mit einem Nachbarsystem betrachtet.

Eine spätere Anbindung externer Systeme ist grundsätzlich möglich, gehört jedoch nicht zum aktuellen Projektumfang.
