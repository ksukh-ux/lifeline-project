# E2 – Glossar

## E2.1 Übersicht

Das Glossar definiert die zentralen fachlichen Begriffe der Lifeline-Anwendung und stellt eine einheitliche Verwendung dieser Begriffe innerhalb der Spezifikation sicher. Es enthält bewusst nur Begriffe, die nicht bereits an anderer Stelle detailliert festgelegt sind: Die einzelnen Kategorie-Werte (Meilenstein, Karriere, Bildung, Beziehung, Reise, Gesundheit, Sonstiges) sind vollständig in D2.4 (Wertebereich der Event-Kategorie) aufgeführt und werden hier nicht als eigene Einträge wiederholt.

| Begriff | Bedeutung |
|---|---|
| Bedeutung (significance) | Numerischer Wert (0–100), der die Wichtigkeit eines Events für die visuelle Gewichtung in der Timeline angibt. |
| Event | Ein persönliches Ereignis oder ein Meilenstein, der von einer Nutzerin bzw. einem Nutzer in Lifeline angelegt und auf der Timeline dargestellt wird. |
| Kategorie | Fachliche Einordnung eines Events, zugleich Grundlage für die farbliche Darstellung in der Timeline. Die zulässigen Werte sind in D2.4 festgelegt. |
| Nutzer:in | Person, die Lifeline verwendet und eigene Events verwalten kann. |
| Timeline | Chronologische Darstellung der Events einer Nutzerin bzw. eines Nutzers. |
